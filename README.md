# MCP System Demo

本项目为 MCP（Model Context Protocol）系统的演示，包括 Python 客户端和 Java 服务端。

## 目录结构
```
client-python/    # Python 客户端
server-java/      # Java 服务端
```

## 环境要求
- Python 3.13+
- Java 17+
- uv 0.8.2

## 快速开始

### 1. 编译 Java 服务端

进入 `server-java` 目录，编译并启动服务：
```shell
cd server-java
# 编译完无须运行，在启动MCP Python 客户端时,会自动启动该服务，并连接服务端
mvn clean package -DskipTests
```

### 2. 启动 Python 客户端

进入 `client-python` 目录，安装依赖：
```shell
cd client-python

# 创建 Python 虚拟环境
uv venv

# 激活 Python 虚拟环境
.venv\Scripts\activate

# 安装依赖
uv pip install .
```

运行主程序：
```shell
# 需要提前将GEMINI_API_KEY的值设置到环境变量中
uv run src/main.py
```

### 4. 主要功能
- 自动连接 MCP Java 服务端
- 获取 MCP 工具列表
- 支持调用 MCP 工具并与 LLM（Gemini）集成

## 代码说明

- `client-python/src/main.py`：Python 客户端入口，负责连接服务端、获取工具、与 LLM 交互。
- `client-python/src/mcp_client.py`：MCP 客户端核心逻辑，负责连接、工具调用、资源管理。
- `server-java/src/main/java/com/guluo/McpServerDemo.java`：MCP Server服务端主程序(Java)。
